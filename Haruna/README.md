# 하루나 (Haruna) — iPhone 앱

> 마음이 쉬어가는 나만의 기록 공간. 작은 기록이 더 좋은 내일을 만들어요.

SwiftUI + SwiftData로 만든 iPhone 네이티브 감정 일기 앱입니다. iPhone 17(iOS 26)에 맞춰 디자인했고, iOS 18 이상 iPhone이면 모두 동작합니다.
서버나 계정 없이 모든 기록은 기기 안에만 저장됩니다.

## 화면 구성

| 탭 | 기능 |
| --- | --- |
| 🏠 오늘 | 마스코트 일러스트 헤더, 날짜 선택(지난 날 기록 가능), 5단계 기분 선택, 자유 글쓰기, 사진 최대 4장 첨부, 저장/수정 |
| 📅 기록 | 캘린더(날마다 기분 얼굴 표시, 좌우 스와이프로 달 이동) / 월별 목록, 날짜를 누르면 그날 기록 카드 |
| 📊 통계 | 최근 7일·30일·90일·전체 기간 선택, 기록한 날·연속 기록·평균 기분, 기분 변화 꺾은선 차트, 기분 비율 도넛 차트, 자주 기록한 키워드 |
| ⭐ 소중한 기록 | 즐겨찾기한 기록 모아보기 (전체 / 즐겨찾기 전환) |
| 기록 상세 | 본문 + 사진 그리드(눌러서 전체 화면), 작성 시각, ☆ 즐겨찾기, 수정, 삭제 |
| ⚙️ 설정 | Face ID 잠금, 매일 알림(시간 지정), 백업 내보내기/불러오기(JSON), 모든 기록 삭제, 테마(시스템/라이트/다크), 자주 묻는 질문, 개인정보 처리방침 |

## iPhone에 설치하기

Mac이 한 대 필요합니다.

1. Mac App Store에서 **Xcode 26** 이상을 설치합니다. (iPhone 17의 iOS 26에 설치하려면 Xcode 26이 필요합니다.)
2. 이 저장소를 내려받아 `Haruna/Haruna.xcodeproj`를 더블클릭해 엽니다.
3. 왼쪽에서 **Haruna** 프로젝트 → **TARGETS: Haruna** → **Signing & Capabilities** 탭으로 갑니다.
   - **Team**에서 본인 Apple ID를 고릅니다. (없으면 `Add an Account...`로 로그인. 무료 Apple ID로도 됩니다.)
   - Bundle Identifier가 겹친다는 오류가 나면 `com.victorteddy.haruna` 뒤에 아무 글자나 붙여 바꿉니다.
4. iPhone을 USB-C 케이블로 Mac에 연결하고, iPhone에서 **이 컴퓨터를 신뢰**를 누릅니다.
5. iPhone **설정 → 개인정보 보호 및 보안 → 개발자 모드**를 켜고 재시동합니다.
6. Xcode 위쪽 기기 목록에서 내 iPhone 17을 고르고 ▶︎(Run) 버튼을 누릅니다.
7. 처음 실행 시 iPhone **설정 → 일반 → VPN 및 기기 관리**에서 내 Apple ID 개발자를 **신뢰**합니다.

> 무료 Apple ID로 설치한 앱은 7일마다 Xcode에서 다시 ▶︎를 눌러 서명을 갱신해야 합니다. 기록은 그대로 남습니다.
> 유료 Apple Developer Program(연 129,000원)에 가입하면 1년간 유지되고 TestFlight로 가족에게도 배포할 수 있습니다.

시뮬레이터로 먼저 보려면 6번에서 기기 대신 **iPhone 17** 시뮬레이터를 고르면 됩니다. Xcode 캔버스의 `#Preview`에는 샘플 기록이 채워져 있습니다.

## 프로젝트 구조

```
Haruna/
├── Haruna.xcodeproj          # Xcode 16+ 동기화 폴더 방식 (파일을 추가하면 자동 포함)
└── Haruna/
    ├── App/                  # 앱 진입점, 탭 구성, 화면 간 라우팅
    ├── Models/               # SwiftData 모델(DiaryEntry, DiaryPhoto), 기분(Mood), 편집 초안
    ├── Views/                # 오늘·기록·통계·소중한 기록·상세·수정·설정·잠금 화면
    ├── Components/           # 기분 얼굴, 카드, 캘린더 칸, 언덕 일러스트, 테마 색상
    ├── Services/             # Face ID, 알림, 백업, 사진 압축, 키워드 추출
    ├── Preview/              # Xcode 미리보기용 샘플 데이터
    └── Assets.xcassets       # 앱 아이콘, 마스코트, 강조색
```

## 설계 메모

- **하루 한 장**: 같은 날짜에 다시 기록하면 그날 기록을 수정합니다. 캘린더·통계가 날짜 단위로 깔끔하게 맞습니다.
- **사진**: 원본은 최대 1600px JPEG로 줄여 SwiftData 외부 저장소에, 목록용 480px 썸네일은 따로 저장해 스크롤이 가볍습니다.
- **잠금**: 앱이 백그라운드로 가면 잠기고, 돌아오면 Face ID → 실패 시 기기 암호로 엽니다.
- **키워드**: 조사·어미를 떼는 가벼운 규칙으로 단어를 세며, 하루에 같은 단어는 한 번만 셉니다.
- **백업**: 사진까지 포함한 JSON 파일. 불러올 때 같은 날짜는 더 최근에 수정된 쪽을 남깁니다.
