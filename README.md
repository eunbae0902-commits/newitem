# TEDDY X 모의거래소

업비트 스타일의 **개인 전용 가상 코인 거래소**입니다.
시세·호가·체결·캔들은 업비트 공개 API(실시간 WebSocket)에서 그대로 받아오고,
돈과 코인은 전부 가상입니다. 서버 없이 브라우저에서만 동작하며 모든 데이터는 이 기기의 `localStorage`에만 저장됩니다.

## 주요 기능

| 영역 | 내용 |
| --- | --- |
| 거래소 | 원화마켓 전체 실시간 시세, 검색·정렬·보유/관심 탭, 캔들차트(1분~일봉, MA5/20/60, 줌·드래그), 실시간 호가·체결 |
| 주문 | 지정가/시장가 매수·매도, 10/25/50/최대 버튼, 호가 클릭 입력, 호가단위 자동 보정, 미체결 주문·취소, 수수료 0.05%, 최소주문 5,000원 |
| 체결 엔진 | 지정가 주문은 실제 시세가 주문가에 닿는 순간 자동 체결 |
| 투자내역 | 보유 KRW·총매수·평가손익·수익률·누적 실현손익, 원금 대비 수익률, 목표 자산 진행바, 포트폴리오 도넛, 거래내역 |
| 자산관리 | KRW 잔고 마음대로 증감/설정, 보유코인 수량·평단가 직접 입력, DCA 자동 적립매수 봇, 목표 자산, 전체 초기화, JSON 백업/복원 |
| 도파민 | 익절 시 컨페티·돈비·금액 팝업·화면 흔들림(수익률 클수록 강하게), 효과음, 총자산 신고가 알림, 업적 배지 15종 |
| 기타 | 다크모드, 모바일 하단 탭 UI, 홈 화면 추가(PWA 매니페스트) |

## 실행 방법

빌드가 필요 없는 정적 웹앱입니다.

- **PC에서 바로**: `index.html`을 브라우저로 열면 됩니다.
- **로컬 서버**: `python3 -m http.server 8000` 후 `http://localhost:8000`
- **휴대폰에서 쓰기**: GitHub 저장소 → Settings → Pages → Branch를 `main` / `(root)`로 지정하면
  `https://<아이디>.github.io/newitem/` 주소가 생깁니다. 휴대폰 브라우저에서 열고 "홈 화면에 추가"하면 앱처럼 사용할 수 있습니다.

> 데이터는 기기·브라우저별로 따로 저장됩니다. 다른 기기로 옮길 때는 자산관리 → 백업 내보내기/불러오기를 이용하세요.

## 파일 구조

```
index.html            화면 구조
css/style.css         업비트 스타일 테마(라이트/다크, 반응형)
js/chart.js           의존성 없는 캔버스 캔들차트
js/app.js             시세 연동, 매매 엔진, 포트폴리오, 효과, 자산관리
manifest.webmanifest  홈 화면 설치 정보
icon.svg              앱 아이콘
```
