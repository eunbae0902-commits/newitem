# 책숨 서재

책을 펼치게 만들고(불씨), 쓰면서 이해하고(사유), 시간을 두고 다시 음미하는(음미) 개인 독서앱.

`app/index.html` 하나로 동작합니다. 브라우저에서 열면 되고, 기록은 브라우저 localStorage에 저장됩니다.

| 탭 | 역할 | 주요 기능 |
|---|---|---|
| 불씨 | 동기부여 | 하루 적립 목표(분), 연속 독서일, 연간 완독 목표, 독서 세션 타이머, 12주 히트맵, '읽고 싶은 이유'가 붙은 다음 책 |
| 서재 | 기록 | 표지 사진 또는 제목 검색으로 저자·출판사·쪽수·소개 자동 입력(Claude 앱/웹에서 열 때), 책 담기, 쪽수 진행률, 완독 처리, 목표 설정, 백업·복원 |
| 사유 | 감상·이해 | 한 문장 요약 · 핵심 개념 3개 · 아홉 살에게 설명하기 · 삶에 연결 · 저자에게 질문 → 이해 깊이 5단계, 구절 담기 |
| 음미 | 회상 | 가장 오래 안 본 문장부터 꺼내는 간격 반복, 3분 머무르기, 다시 읽을 때마다 쌓이는 '생각의 층' |
