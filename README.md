# TEDDY X 모의거래소

> 📱 감정 일기 앱 **하루나**: [`haruna/`](haruna/) 폴더는 Mac 없이 iPhone 홈 화면에 바로 설치하는 웹앱(`https://<아이디>.github.io/newitem/haruna/`),
> [`Haruna/`](Haruna/README.md) 폴더는 Xcode용 네이티브 SwiftUI 버전입니다.

업비트 스타일의 **개인 전용 가상 코인 거래소**입니다.
시세·호가·체결·캔들은 업비트 공개 API(실시간 WebSocket)에서 그대로 받아오고,
돈과 코인은 전부 가상입니다. 서버 없이 브라우저에서만 동작하며 모든 데이터는 이 기기의 `localStorage`에만 저장됩니다.

## 주요 기능

| 영역 | 내용 |
| --- | --- |
| 거래소 | 원화마켓 전체 실시간 시세, 검색·정렬·보유/관심 탭, 캔들차트(1분~일봉, MA5/20/60, 줌·드래그), 실시간 호가·체결 |
| 주문 | 지정가/시장가 매수·매도, 10/25/50/최대 버튼, 호가 클릭 입력, 호가단위 자동 보정, 미체결 주문·취소, 수수료 0.05%, 최소주문 5,000원 |
| 체결 엔진 | 지정가 주문은 실제 시세가 주문가에 닿는 순간 자동 체결 |
| 투자내역 | 보유 KRW·총매수·평가손익·수익률·누적 실현손익, 원금 대비 수익률, 목표 자산 진행바, 포트폴리오 도넛, 거래내역 |
| 자산관리 | KRW 잔고 마음대로 증감/설정, 보유코인 수량·평단가 직접 입력, DCA 자동 적립매수 봇, 목표 자산, 전체 초기화, JSON 백업/복원 |
| 도파민 | 익절 시 컨페티·돈비·금액 팝업·화면 흔들림(수익률 클수록 강하게), 효과음, 총자산 신고가 알림, 업적 배지 15종 |
| 기타 | 다크모드, 모바일 하단 탭 UI, 홈 화면 추가(PWA 매니페스트) |

## 👪 가족 모드 (마스터 = 대표님)

서버 없이도 **마스터만 투자금을 지급·회수**할 수 있도록 전자서명(ECDSA P-256)을 사용합니다.

| 역할 | 할 수 있는 것 | 할 수 없는 것 |
| --- | --- | --- |
| 👑 마스터 | 자기 자산 자유 조정, 가족 초대, 지급·회수·초기화 코드 발급, 랭킹 공유, PIN 잠금 | - |
| 👩👦 가족 | 받은 돈으로 매매, DCA 봇, 성적표 보내기, 랭킹 보기 | KRW·코인 직접 조정, 전체 초기화, 백업 불러오기 |

**사용 순서**
1. 대표님 폰에서 앱 첫 실행 → **마스터로 시작**
2. 자산관리 → **가족 관리**에서 이름·시작 투자금 입력 → **초대 링크 만들기** → 카톡으로 전송
3. 가족이 링크를 열면 그 금액으로 자동 참여 (가족 폰에서는 "마스터로 시작"을 누르지 않도록 안내)
4. 추가 지급/회수/초기화: 가족 카드에 금액 입력 → **＋지급 / －회수 / 초기화** → 생성된 링크 전송
5. 가족이 **내 성적표 보내기** → 마스터가 붙여넣기 → **랭킹을 가족에게 공유**

**보안 원리**
- 마스터 기기에서 만든 개인키로 모든 지급 코드에 서명하고, 가족 기기는 초대 때 받은 공개키로 검증합니다.
  금액을 바꾸거나 다른 키로 만든 코드는 거부됩니다.
- 코드마다 1회용 번호가 있어 같은 코드를 두 번 쓸 수 없고, 다른 가족의 코드는 쓸 수 없습니다.
- 마스터 PIN을 설정하면 대표님 폰에서도 PIN 없이는 자산관리 화면이 열리지 않습니다.
- 가족용 게임 수준의 보호입니다. 브라우저 개발자도구로 저장소를 직접 고치는 것까지 막지는 못합니다.
- 마스터 백업 파일에는 개인키가 들어 있으니 안전하게 보관하세요. 마스터 폰을 잃고 백업도 없으면 가족을 다시 초대해야 합니다.

## 🎰 카지노 (가상 머니)

| 게임 | 방식 | 기댓값 |
| --- | --- | --- |
| 🎰 슬롯 | 3릴, 7-7-7 777배 ~ 🍒 2개 1.5배 | 97.3% (적중률 27%) |
| 🚀 떡상 크래시 | 배수가 오르다 무작위 지점에서 폭발, 그 전에 익절 (자동 익절 지원) | 99% |
| 🪙 코인 플립 | ₿/Ξ 맞히면 1.95배, 연승 표시 | 97.5% |

- 보유 KRW로 베팅하며 결과는 총자산에 그대로 반영됩니다. 난수는 `crypto.getRandomValues`를 씁니다.
- 모든 게임에 하우스 엣지가 있어 오래 할수록 조금씩 잃도록 설계돼 있습니다 (실제 도박의 구조 체험).
- **가족 기기는 기본 잠김.** 마스터가 가족 카드의 🎰 버튼으로 허용/차단 코드와 **하루 손실 한도**를 보낼 수 있습니다.
- 카지노 손익은 성적표에 함께 실려 마스터 화면에 표시됩니다.

## 실행 방법

빌드가 필요 없는 정적 웹앱입니다.

- **PC에서 바로**: `index.html`을 브라우저로 열면 됩니다.
- **로컬 서버**: `python3 -m http.server 8000` 후 `http://localhost:8000`
- **휴대폰에서 쓰기**: GitHub 저장소 → Settings → Pages → Branch를 `main` / `(root)`로 지정하면
  `https://<아이디>.github.io/newitem/` 주소가 생깁니다. 휴대폰 브라우저에서 열고 "홈 화면에 추가"하면 앱처럼 사용할 수 있습니다.

### 📲 휴대폰 앱으로 설치
앱 안의 **자산관리 → ⚙️ 설정 → "휴대폰에 앱으로 설치하기"** 버튼을 누르면 기기에 맞는 안내가 나옵니다.
- **아이폰**: Safari → 공유(□↑) → 홈 화면에 추가
- **안드로이드**: Chrome → ⋮ → 앱 설치 (설치 팝업이 바로 뜨기도 함)
- 카톡 안에서 열었다면 먼저 Safari/Chrome으로 다시 열기
- 설치한 앱은 브라우저와 저장공간이 따로일 수 있으니, 가족은 **앱 설치 후 초대·지급 링크를 복사해 앱 안에 붙여넣기(📋)** 하세요.

> 데이터는 기기·브라우저별로 따로 저장됩니다. 다른 기기로 옮길 때는 자산관리 → 백업 내보내기/불러오기를 이용하세요.

## 시세 연결 방식 (업비트 브라우저 요청 제한 대응)
업비트는 브라우저에서 오는 요청을 **REST·WebSocket 연결 모두 10초당 1회**로 제한합니다.
- 전체 시세·호가·체결은 **WebSocket 연결 1개**로 받고, 코인을 바꿀 때는 같은 연결에 구독만 다시 보냅니다.
- 원화마켓 목록은 `js/markets.js`에 내장(하루 1회 자동 갱신)해 시작할 때 REST 요청이 없습니다.
- 차트 기록만 REST로 받으며, 10.5초 간격 대기열과 캐시로 제한을 넘지 않습니다. 기록이 오기 전에는 실시간 체결로 캔들을 그립니다.
- 새로고침 직후에도 마지막 요청 시각을 기억해 제한에 걸리지 않습니다.
